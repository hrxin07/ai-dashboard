# Task 11：完成学习实践任务页面

**阶段：** 职业探索与学习实践  
**状态：** 已完成

## 目标
提供学习任务的可视化管理页面，包括任务进度、进度条和可编辑的小任务清单。

## 验收标准
- [x] 用户可以新增、编辑、删除任务，删除前必须确认。
- [x] 无小任务时可用滑块设置 0–100% 完成进度。
- [x] 可添加、修改、删除小任务并切换完成状态；有小任务时进度自动计算。
- [x] 任务卡片展示进度条、小任务完成数量，并区分已完成任务。
- [x] 支持状态、类型、优先级筛选，空列表和操作结果有提示。

## 验证方式
- [x] `npm run lint` 与 `npm run build` 通过。
- [x] 完成新增任务、添加小任务、编辑、切换小任务完成状态和删除全流程。
